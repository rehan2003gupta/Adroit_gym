# Adroit Gym 🏋️

A modern, responsive gym website built with React, Tailwind CSS and Firebase. Adroit Gym provides an engaging digital experience for fitness enthusiasts to explore the gym, discover membership plans, and get in touch.

🔗 **Live Website:** [Adroit Gym](https://adroit-gym.vercel.app/)

---

## 📌 Overview

Adroit Gym is a frontend-focused gym website designed to showcase a gym's services, membership offerings, and overall fitness experience through a clean and responsive interface.

The project focuses on reusable React components, responsive UI design, navigation, interactive forms, and integration with cloud services.

## ✨ Features

- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Modern UI** – Clean layouts, visually engaging sections, and styling using Tailwind CSS.
- **Membership Plans** – Displays gym membership options and plans.
- **Multi-page Navigation** – Navigation between different sections and pages using React Router.
- **Interactive Forms** – Form interfaces for user interaction and information collection.
- **Reusable Components** – Modular React components for maintainable code.
- **Cloud Integration** – Firebase and Appwrite dependencies included for application integrations.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/rehan2003gupta/Adroit_gym.git
```

### 2. Navigate to the project directory

```bash
cd Adroit_gym
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser to view the website.

## 🌐 Deployment

The website is deployed using Vercel and Cloudflare Pages.

To deploy your own version:

1. Fork or clone this repository.
2. Push the project to your GitHub account.
3. Import the repository into Vercel.
4. Configure the build settings if required.
5. Deploy the project.
